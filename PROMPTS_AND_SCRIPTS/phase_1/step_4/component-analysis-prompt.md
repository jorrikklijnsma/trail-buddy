```
I need to refactor the following React component in an existing codebase. Using the component code and the codebase analysis provided, please help me understand:

## Component to Refactor
[PASTE THE COMPONENT CODE HERE]

## Codebase Context
[PASTE RELEVANT SECTIONS FROM THE CODEBASE SUMMARY]

## Available Utilities and Components
[PASTE ANALYSIS OF RELATED UTILITIES, COMPONENTS, AND TYPES]

Please analyze this component and provide:

1. **Component Function** - What this component does and its role in the application

2. **Current Implementation Issues** - Identify problems with the current implementation including:
   - Technical debt or code smells
   - Anti-patterns
   - Performance concerns
   - TypeScript/type safety issues
   - Outdated React patterns

3. **Dependencies and Relationships** - How this component relates to other parts of the codebase:
   - What components, hooks, or utilities it uses
   - What components use it
   - Context dependencies
   - Data flow

4. **Refactoring Recommendations** - Specific suggestions for improvement:
   - Modern patterns to apply
   - Components that could be reused
   - Functions that could be extracted
   - Type improvements

5. **Refactoring Approach** - A step-by-step plan for refactoring this component while maintaining functionality

6. **Other Files to Consider** - List any other specific files I should examine or modify as part of this refactoring

If you need additional information about any specific file or component to complete your analysis, please indicate what you need and why it would be helpful.
```
